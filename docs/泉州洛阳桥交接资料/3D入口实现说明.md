# 洛阳桥 3D 入口第一版

本版延续默认花园的 Three.js 三维形式。照片仅作为建模构图参考，场景不使用照片背景或二维角色贴图。建模属于参考照片后的风格化重建，未做实地测绘；桥梁比例、入口距离和远岸轮廓为演示调整。

## 体验

打开项目 `index.html`，点击“城市疗愈 → 模拟定位泉州 → 进入洛阳桥”。

- 鼠标或单指拖动：自由环绕镜头。
- 鼠标滚轮或双指手势：缩放；鼠标右键或双指拖动：平移。
- 点击人物：跟随人物；再点击石板路：人物寻路走向落点，小猫跟随。
- 点击小猫或“摸摸小猫”：小猫回应抚摸。
- “走上桥”：人物实际从桥头沿石板路进入桥段，镜头跟随。
- 桥头、桥上、左看、右看：同一个世界内的镜头预设，角色不会传送。
- 键盘方向键旋转，`+` / `-` 缩放，`0` 返回桥头全景，WASD 让人物移动。
- 开始陪伴后播放合成水声与风声；停留约 12 秒蹭腿、36 秒轻跳，用于首版演示。暂停期间不累计触发时间；行走会中断当前动作并重新计时。

## 资源与代码

- `city-scene.js`：石碑、牌匾、榕树、树根、双石塔、石板路、栏杆、船形桥墩、潮水、滩涂和远岸的三维几何与材质。
- `city-water.js`：参考图 07 的灰绿潮水；多尺度不规则波纹、随视角变化的反光及桥墩／树木的动态平面倒影。桥两侧保持连续水域，滩涂退到远处，石墩水线附近加深。程序生成，无需额外水面贴图。
- `city-stone.js`：参考图 03／04／05／09 制作的灰白花岗岩颗粒、矿物色差和凹凸材质，以及具有磨边缺角的石块几何。入口为错缝横向石板，桥面为四列长短不一的条石；石塔、双石亭、栏杆、逐层砌筑的船形桥墩共用世界尺度材质。桥两侧补充小船、远岸低层村屋、树带及楼房，使用偏冷的多云日光。材质与几何为程序重建，无外部下载依赖。
- `city-person.js`：原创白色连帽衫、棕发、长裤、浅色鞋人物。头部、肩、肘、髋和膝关节驱动程序步态。
- `story-cat.js` / `story-cat-coat.js`：复用花园现有的骨骼与毛绒材质小猫；城市使用独立实例。
- `city-world.js`：Three.js 场景、镜头、拾取、人物寻路、小猫跟随和互动。
- `city-experience.js` / `city-world.css`：城市入口、模拟定位、陪伴计时和轻量控制面板。
- `city-soundscape.js`：浏览器合成环境声，不是洛阳桥实地录音。
- `tests/city-world.test.mjs`：三维体积、可走区域、人物关节、角色跟随、视角与行走独立、小猫停留互动测试。

进入城市时暂停花园声音与绘制；离开城市时停止城市声音与绘制，恢复花园画面。城市实例按需创建，重复进入复用，不重复创建画布。构建脚本将三维模块、样式和控制逻辑打包到 `index.html`，可直接本地打开。

## 当前边界

人物和石构为程序建模，未输出单独 GLB。首版覆盖桥头和一段可行走石桥，暂不制作整座古桥或实景精确复刻。模拟定位，不调用真实 GPS；环境声为合成氛围音。
