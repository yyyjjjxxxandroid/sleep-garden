# 小猫轻声回应与陪伴验收

2026-10-26。本次实现将真实 AI 回复交给本机语音模型朗读，搭配少量实录猫声。没有用预录安慰话替代模型回复。

## 选型

- [Kokoro-82M v1.1-zh](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)：Apache-2.0 中文开放权重，采用官方量化 ONNX 版本，模型包约 147 MB。
- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)：Apache-2.0，本机 CPU 推理，无需额外语音 API Key。首次运行加载模型，后续复用同一私有进程。
- 预设中文音色 zf_026，速度 0.88，语音峰值限制、句首句尾淡入淡出。它是中文人声，不是猫叫声转语音，也不是克隆声音；目前不支持精细情绪韵律指令。音色好感和自然度需要真人试听。
- 喵声：TBMcQueen 的 Mavis_cat-meow-soft_01；呼噜：JamesBradford 的 Cat Purring。均已确认 CC0，来源、处理记录在 `audio/companion/sources.json`。

语音模型和依赖按需安装，不放入仓库或离线 HTML。每位队友先运行 `npm run setup:voice`，再运行 `npm start`。AI 文字服务使用每位队友自己的 `.env` Key。

## 陪伴行为

先回应用户的具体经历，再考虑是否提出方法；倾诉不触发换景调音。回复避免要求积极、空泛夸奖、每轮追问和排他依赖。安静请求只留文字。猫叫用于轻松互动，难过或严重困扰时不用；客户端另限制猫声至少间隔一分钟。

本次对实际配置模型 gpt-5.6-sol 发起五组请求，全部成功返回。以下为本次生成结果节选，不代表每次生成相同：

| 用户表达 | 实际回复节选 | 观察 |
| --- | --- | --- |
| 改了三遍方案，领导仍说不行，有点委屈 | “改了三遍还是只等来一句‘不行’……今天可以先不用替这份方案、也不用替自己解释。” | 回应具体经历，无猫声、无调音 |
| 明天汇报，越想睡越睡不着 | “今晚越逼自己睡，心里反而越紧……如果你愿意，可以只告诉我最担心汇报里的哪一小段。” | 承接汇报焦虑，无猫声、无调音 |

| 摸摸你的头，轻轻喵一声 | “你好呀，给你摸摸头。” | soft / meow |

这验证了接入和本次生成行为；“情绪价值是否到位”还没有用户研究结论。下一步可让用户对比文字版、普通朗读版和小猫轻声版，评价被理解感、打扰程度、声音自然度与再次使用意愿。
