# 小猫 Agent：文字陪伴与环境控制

2026-10-26。当前小猫只支持文字对话；按住说话、语音识别、小猫回复朗读、Kokoro 合成接口与安装脚本均已移除。独立的「录下宠物的声音」保留，仅在本机保存并用于摸猫时的原声回放。

## 已接入的能力

- 花园：晴朗、阴天、细雨、雪、雾、彩虹、极光、流星；白天、黄昏、夜色；视觉风力、光照、风声联动、萤火虫、减少动态、恢复跟随本地天气与时间。
- 声音：鸟鸣、风、雨、虫鸣、呼噜、流水、猫咪脚步、风铃、音乐九个通道；模型音量限定为 0–60%。脚步和风铃由真实动作/风触发，不是持续音源。
- 花园定时：1–720 分钟，0 为取消；没有提供则保持原定时。采用后从当前累计时长向后计时，暂停时不会自动继续，已累计的陪伴时长不会清零。
- 场景：花园、泉州洛阳桥、广州珠江边、深圳湾。城市支持黄昏/夜色、水/风/音乐及小猫动作；城市尚无天气、光照和定时能力，这些请求会明确说明需要回花园。
- 小猫：靠近、摸头、休息；偏好仍需用户主动确认保存。只倾诉时保持现有环境。

示例：「回花园，换成雨夜，风力20%，光照25%，关掉鸟鸣和萤火虫，20分钟后结束。」

## 执行方式与边界

真实模型结合当前场景、混音、环境设置、定时/剩余时间、最近成功对话和确认偏好生成结构化增量方案。前后端共用 `companion-plan.js` 白名单，拒绝城市中不可执行的控制，不执行任意脚本或模型提供的链接。控制卡片列出修改项，用户点击「就这样陪我」后，经原有场景、混音与计时逻辑执行，不会自动启动声音。

未提及的设置不变；视觉风力单独调节时默认解除风声联动，明确开启联动时风力/风声音量最高同步到60%。细雨天气默认设置35%雨声，其他天气默认关闭雨声，卡片显示此变化；明确要求的雨声音量优先。晴朗不会把夜晚强制切回白天，极光/流星自动配夜色，彩虹配白天。手动调节天气/时间/光照会停止相应本地自动跟随；恢复本地跟随时若定位/网络不可用，沿用原有缓存/预设机制。暂停期间画面保持冻结，继续后恢复本地更新。

对话不使用麦克风，不请求合成接口；模型凭证始终从队友自己的 `.env` 在服务端读取，不进入 Git 或浏览器。没有自动识别情绪、检测睡着、AI 作曲或疗效结论。

## 验证

- `npm test`：包含动作边界、天气与昼夜兼容、风声联动、定时边界、状态快照过滤、城市能力校验及已删除语音接口回归。
- `node tests/browser-companion-agent.mjs`：需项目服务与独立 Chrome 调试端口9558；以受控模型方案验证真实界面/花园执行链路、采用前不修改、自动天气不覆盖、暂停与定时同步、城市往返、桌面及390/320像素手机布局，并确认没有麦克风/合成请求。这不评价真实模型理解准确率。
- `node tests/browser-pet-voice.mjs`：以生成的音频轨道测试真实 MediaRecorder，覆盖宠物录音保留、权限拒绝、退出释放、8秒上限、保存与回放。
- 本轮已通过本机 `/api/companion` 真实请求验证配置的 `gpt-5.6-sol`：复合雨夜/音量/光照/定时请求返回可执行方案；深圳湾雨景/定时请求明确转回花园。具体理解仍依赖上游模型，不能据两组冒烟测试推断全面可靠性。
