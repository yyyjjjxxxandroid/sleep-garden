# Quaternius Stylized Nature MegaKit — curated Standard subset

These are original, unmodified glTF 2.0 files from the free **Standard** subset of
Quaternius' Stylized Nature MegaKit.  The related `.bin` geometry buffers and PNG
textures remain beside each `.gltf`; use the `.gltf` file as the entry point.

## Curated entry models

- Broadleaf canopy: `CommonTree_1` through `CommonTree_5`
- Flowering understory: `Bush_Common_Flowers`, `Flower_3_Group`,
  `Flower_3_Single`, `Flower_4_Group`, `Flower_4_Single`
- Ground cover: `Grass_Common_Tall`, `Grass_Common_Short`, `Grass_Wispy_Tall`
- Garden stones: `Rock_Medium_1`, `Rock_Medium_2`, `Rock_Medium_3`,
  `RockPath_Round_Wide`

The folder intentionally excludes the paid Pro and Source-only material.
