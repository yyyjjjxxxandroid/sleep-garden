# 眠境花园

面向“音乐 × AI 陪伴”的音乐疗愈花园 Demo。

当前主线是：对小猫说一句需求 → AI 提出音乐、自然声、天气环境、定时、城市/花园与小猫动作安排 → 用户采用后执行 → 经用户确认保存声音与场景偏好。首页状态按钮仍使用本机规则，AI 对话则实际调用配置的模型；未接入时明确显示不可用。3D 花园与广州、深圳、泉州漫游作为陪伴空间。

## 启动 AI 小猫

```bash
cp .env.example .env
# 在本机 .env 填写自己的 AI_API_KEY
npm start
```

需要 Node.js 20 或更新版本。打开 <http://127.0.0.1:8766/index.html>，点击“和小猫说说”。项目现在通过服务端直连 YLS 的 `https://code.ylsagi.com/codex`，选择 `gpt-5.6-sol`；队友不需要安装 Codex 或启动本机模型转发服务。已提交的 `index.html` 可直接运行，仅修改源码并重新构建时需要安装开发依赖。

Git 仓库不包含真实 Key。团队成员拉取 `main` 分支后，复制 `.env.example` 为 `.env`，填写**各自的 API Key**（确认文件名不是 `.env.txt`），再运行 `npm start`。请勿把 `.env` 上传到仓库。修改配置后重启服务；每人的模型权限、余额与额度取决于自己的账号。

Responses 接口用 `AI_WIRE_API=responses`；兼容 Chat Completions 的平台用 `AI_WIRE_API=chat`。更换平台时一起修改 `AI_BASE_URL`、`AI_API_KEY` 和 `AI_MODEL`。凭证仅在服务端读取，不进入浏览器和构建产物，`.env` 已被 Git 忽略。开发者仍可显式设置 `AI_USE_CODEX_PROVIDER=true`，从本机 `~/.codex/config.toml` 读取所选 provider 的普通 API Token，不读取 ChatGPT/OAuth 登录凭证。

在浏览器访问 <http://127.0.0.1:8766/api/companion/status> 可检查配置；`configured:true` 只说明配置已读取，模型调用权限需要实际给小猫发送一句话验证。若只用静态文件预览或 Python 静态服务器，AI 接口不可用，请通过 `npm start` 启动。

`npm start` 仅允许电脑本机访问。手机局域网预览使用下面的 `npm run start:lan`。独立部署需要另外接入服务端凭证、用户认证及额度管理，不要将当前开发服务直接暴露到公网。

示例：“今天有点累，不想聊天，陪我去深圳湾坐一会儿，风声轻一点。”点击“就这样陪我”采用安排，再点“听听这段”开启播放，以满足手机浏览器的用户手势要求。已有播放中的同场景只调整混音，不重置计时。

偏好只在点击“把这个偏好记住”后保存，可随时清除；对话仅留在当前页面，清空/刷新后移除。发送时，当前消息、最近 8 条成功对话、当前场景、声音、环境设置、定时与确认偏好会发送至配置的 AI 服务。服务端不存储对话，Responses 请求使用 `store:false`；上游服务仍遵循其自身数据政策。

“和小猫说说”只支持文字输入，不使用语音识别或回复朗读，也不请求麦克风。宠物叫声录制作为独立功能保留。

小猫 Agent 已接入花园的八种天气（晴朗、阴天、细雨、雪、雾、彩虹、极光、流星）、白天/黄昏/夜色、风力、光照、风声联动、萤火虫、减少动态、恢复跟随本地天气与时间、全部九条混音通道及 0–720 分钟定时。示例：“换成雨夜，风力20%，光照25%，关掉鸟鸣，20分钟后结束。”先查看调整卡片，点击「就这样陪我」执行。只聊天不会改动设置；未提及的设置保留。极光/流星配夜色，彩虹配白天；换天气默认同步雨声，卡片会列出音量。

城市漫游仍支持切换城市、黄昏/夜色、水声/风声/音乐和小猫动作；天气、光照与陪伴定时目前仅花园支持。城市中提出这些需求时，小猫会说明并提供回花园的方案。改定时从采用时的已累计时长往后计时，不重置陪伴进度，暂停时等待继续播放。所有方案均不会自动启动声音。实现边界见 [小猫 Agent](./docs/companion-agent.md)。

当前曲库只有一首已授权 Lo-fi 和六种自然/陪伴录音；AI 可以编排混音，不能检索或切换不存在的歌曲。没有 AI 作曲、自动情绪识别或睡眠检测。

## 用照片定制小猫（演示版）

开始陪伴后，点左上角小猫图标 →「用照片定制我的小猫」。上传主体居中的 JPG、PNG 或 WebP 近照（最大 8 MB），浏览器会从中央区域提取毛色；可调整主要毛色、花纹色、纯色 / 白胸双色 / 虎斑 / 重点色与名字，查看真实三维小猫的近照，再「保存并带进花园」。没有照片也可试选三种示例毛色。退出未保存的预览会恢复，保存后刷新仍保留，可随时恢复原来的小猫。原有摸头、散步、睡觉、换装与拍照动作继续使用。

这是本地照片换肤原型，**没有调用图像 AI，也没有从照片重建体型或完整 3D 模型**。颜色提取可能受背景影响，需要手动校正；现阶段仅适配现有猫的骨架。照片不上传服务器，只在本机保存经缩小的 JPEG 缩略图、名字与外观参数；保存失败时会提示仅本次有效。

## 录下宠物的声音（演示版）

开始陪伴后，点左上角小猫图标 →「录下宠物的声音」。可录制最多 8 秒叫声，或导入已有音频（最大 10 MB，取前 8 秒），试听后点击「用作猫叫」。继续播放陪伴声音，摸头或挠下巴时会播放录音；录音仅保存在本机浏览器，刷新后保留，支持恢复默认。录音会暂停花园声音与计时，需手动继续；取消、退出面板、切到后台会停止录音并释放麦克风。

这个功能只替换摸猫时的叫声。麦克风需 HTTPS 或 localhost 与浏览器授权；这是原声回放，不是声音克隆。宠物录音只保存在本机，不上传给 AI 服务。

## 离线打开体验

- 电脑：用浏览器打开 `index.html`。
- 手机：将 `index.html` 保存到手机，选择「用浏览器打开」。如果手机只能预览本地文件，可将 `index.html` 发布为网页，再用手机浏览器访问网页链接。

## 在手机浏览器中体验

1. 手机和电脑连接同一个可信 Wi-Fi，在电脑的项目目录运行 `npm run start:lan`。
2. 终端会显示「手机访问：http://电脑的局域网地址:8766/index.html」，用手机 Safari 或 Chrome 打开该地址。手机上的 `localhost` 指向手机自身，请使用终端显示的局域网地址。
3. 单指在场景空白处滑动可旋转视角，两指张开/合拢可放大/缩小，两指同向拖动可平移。在城市中轻点可见步道，人物会绕开障碍走过去，小猫会跟随；花园中轻点可行走的草地，小猫会走过去。滑动和缩放结束不会下达行走指令。
4. 保持电脑服务运行；按 Ctrl+C 停止共享。如果无法连接，检查电脑防火墙是否允许 Node.js 的局域网连接，以及 Wi-Fi 是否启用了访客隔离。

局域网模式只接受本机的私有 IPv4 地址，保留同源检查与敏感文件屏蔽；同一网络中能访问该地址的人也能使用 AI 接口，因此仅用于可信网络预览。HTTP 局域网预览支持场景操作与点击后播放音乐；麦克风录制需 HTTPS，可改用导入已有音频。

打开后可直接点「听听今晚的音乐」，也可选「思绪很多 / 想被陪伴 / 有点困了」。可选设置支持环境、耳机和开始前感受；播放中可进入低亮度听音或一分钟呼吸引导。定时后安静结束，感受可以下次补记。

当前网页版切后台或锁屏会暂停，低亮度界面仅支持前台听音。产品定位、赛题映射、演示流程与待验证指标见 [比赛产品方案](./比赛产品方案.md)。

## 源码结构

- `server.mjs` / `ai-service.mjs`：本地静态服务、服务端凭证读取与真实模型请求
- `companion-plan.js`：前后端共用的动作白名单与音量校验
- `ai-companion.js` / `ai-companion.css`：小猫文字对话、采用安排与确认偏好
- `source.html`：页面结构和产品交互
- `garden-personalization.js`：可解释推荐与有效反馈统计
- `garden-experience.js` / `garden-experience.css`：今晚状态、低亮度听音、呼吸与感受回访
- `story-world.js`：当前绘本风格 Three.js 世界
- `world-base.js`：3D 场景基础能力
- `story-cat.js`：陪伴宠物模型和动画
- `story-detail.js` / `story-atmosphere.js`：场景细节与氛围
- `assets3d-v2/`：Quaternius Stylized Nature MegaKit 的本地模型资源
- `audio/`：六条 CC0 自然实录、一条可选背景音乐、来源与质量报告
- `garden-audio.js`：手势后初始化的 Web Audio 混音、淡入淡出、循环边缘修复和中断同步
- `build3d.py`：重新打包离线单文件 HTML
- `index.html`：可直接演示的打包产物

## 修改源码后重新构建（开发者使用）

手机端采用独立渲染预算：最高 1 倍像素比、关闭实时阴影与抗锯齿、水面倒影最多每 100ms 更新一次。连续慢帧会逐步降低渲染分辨率，稳定后再缓慢恢复。花园静态模型按空间分区合批并裁剪，远处植物自动切换低模，靠近恢复原模型；花园与城市小猫共用手机毛发预算，保留骨骼动作和换肤。桌面继续按设备性能选择画质。

自然模型修改后，先离线生成远景低模，再构建，避免在手机动画线程上进行减面：

```bash
node scripts/build-nature-lod.mjs
npm run build
```

修改源码后，使用 Node.js、esbuild 和 Python 3 重新生成 `index.html`：

```bash
npm install
npm run build
```

重新下载并处理声音素材（需要 FFmpeg 和网络）：

```bash
python3 scripts/update_audio_assets.py
python3 scripts/check_audio_assets.py
```
